# Omni10 vs GodMode9 (direction)

GodMode9 is mature (NAND, scripts, hex, titles, …). Omni10 aims for a **different, modern stack**, not a clone.

| Area | GM9 | Omni10 direction |
|------|-----|------------------|
| Scripts | `.gm9` | **o10script** / opaque `.o10` on-device + **Lua** later |
| Branding | GM9 | Omni10 EN-first, multi-lang |
| Install UX | Manual firm | **O10-Inst-Booter** CIA + auto release |
| Dual core | ARM9-focused | **ARM9 + ARM11** section planned |
| Assets | Classic | Generated **icon/banner/splash/sound** |
| Network | Limited | FTP goal in FIRM after NWM |
| Flashcart UX | ntrboot docs elsewhere | In-app warn + LED sequence |

**Today:** Omni10 is **not** feature-complete vs GM9. Goal is to **surpass** on scripting, installer UX, dual-core, and packaging — while matching critical FS/NAND tools over time.
