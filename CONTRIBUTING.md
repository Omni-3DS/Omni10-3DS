# Contributing to Omni10-3DS

Thanks for your interest in contributing!

## Current Status

The project is in early development. The repository currently contains:

- Project structure
- Headers & stubs for core modules (UI, FS, Net/FTP, .o10 engine)
- Documentation for Lua API and `.o10` scripting
- Example scripts
- GitHub Actions CI

## How to contribute

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/my-feature`)
3. Make your changes
4. Test what you can
5. Open a Pull Request

## Code style

- C11
- 4 spaces indentation
- Clear and readable names
- Comments for non-obvious parts

## Priority areas

- Real ARM9 / ARM11 FIRM code
- File system (FatFS integration)
- UI / framebuffer drawing
- `.o10` parser & runtime
- Lua bindings
- FTP server (ARM11)
- Splash screen rendering
